# STORAGE&MESS LoRa

Клиент мессенджера STORAGE&MESS для сетей **Meshtastic**: переписка без
интернета и без сотовой связи, через LoRa-узлы. Работает на **STM32**
(Black Pill F411, Blue Pill F103) и на Linux — одним и тем же ядром на C99.

```
 [консоль / терминал] ── UART ── [STM32 + smess-lora] ── UART ── [узел Meshtastic] ))) LoRa )))
```

STM32 не занимается радио сам: эфиром, маршрутом, повторами и ключом канала
ведает узел Meshtastic (Heltec, T-Beam, RAK и т. п.), подключённый по Serial
API. Клиент поверх этого даёт сообщения STORAGE&MESS: адреса людей, длинные
тексты кусками, отсев повторов, точку подключения шифрования содержимого.

## Что умеет

- подключение к узлу по Serial API (кадры `0x94 0xC3`, protobuf), список узлов сети;
- сообщения STORAGE&MESS — порт `PRIVATE_APP` (256), свой компактный конверт:
  19 байт заголовка, 214 байт текста на кадр, до 8 кадров (1712 байт) на сообщение;
- обычные сообщения Meshtastic (`TEXT_MESSAGE_APP`) — видны в их приложениях;
- личные (с подтверждением доставки узлом) и всем в канале;
- никакой динамической памяти; ядро не знает, на чём запущено.

## Сборка и проверка на ПК

```bash
make            # build/smess-lora — клиент для Linux
make test       # проверки ядра + сверка с эталонной библиотекой Meshtastic
./build/smess-lora /dev/ttyUSB0
```

`make test` требует `pip install meshtastic`: наш кодек проверяется против
официальных protobuf-описаний в обе стороны (`tests/interop.py`).

## Прошивка STM32

Нужны `arm-none-eabi-gcc` и [libopencm3](https://github.com/libopencm3/libopencm3)
(собранная, путь — `OPENCM3_DIR`, по умолчанию `~/.local/libopencm3`).

```bash
make stm32                              # Black Pill (STM32F411CEU6)
make -C port/stm32 BOARD=bluepill       # Blue Pill (STM32F103C8T6)
make -C port/stm32 flash                # через ST-Link
```

| Вывод STM32 | Куда |
|---|---|
| PA2 (USART2 TX) | RX узла Meshtastic |
| PA3 (USART2 RX) | TX узла Meshtastic |
| PA9 (USART1 TX) | RX USB-UART адаптера (консоль) |
| PA10 (USART1 RX) | TX USB-UART адаптера |
| GND | общая земля со всеми |
| PC13 | светодиод: мигает — подключаюсь, горит — на связи |

Скорость обоих портов — 115200. На узле в прошивках 2.5+ должна быть включена
**Security → Serial console**, иначе после загрузки он перестаёт отвечать по UART.

## Команды консоли

| | |
|---|---|
| `текст` | сообщение STORAGE&MESS текущему адресату |
| `/to all` · `/to !a1b2c3d4` · `/to имя` | адресат |
| `/mesh текст` | обычное сообщение Meshtastic |
| `/nodes` | узлы сети |
| `/ch N` | канал узла |
| `/info` | состояние |

## Шифрование содержимого

Эфир Meshtastic закрыт ключом канала (AES). Собственное сквозное шифрование
сообщений STORAGE&MESS — **закрытая часть проекта** и в этот репозиторий не
входит. Здесь только интерфейс (`core/smesh_crypto.h`) и открытая заглушка
(`core/crypto_null.c`), с которой клиент полностью работоспособен.
Закрытая реализация подключается при сборке: `make CRYPTO=private`.

## Устройство

| | |
|---|---|
| `core/pb.*` | минимальный protobuf без зависимостей |
| `core/mt.*` | Serial API Meshtastic: кадры, разбор потока, ToRadio/FromRadio |
| `core/smesh.*` | конверт STORAGE&MESS, нарезка и сборка, отсев повторов |
| `core/app.*` | клиент: подключение, команды, отправка с паузами между кадрами |
| `port/linux` | порт для Linux (узел по USB) |
| `port/stm32` | порт для STM32 на libopencm3 |

## Правила

STORAGE&MESS не является средством массовой информации. Всё, что передаётся
через клиент, — сообщения пользователей, и за их содержание отвечает автор.
Не используйте сервис для противозаконного и опасного: насилия, экстремизма,
наркотиков, мошенничества, распространения чужих персональных данных.
Мы за мир, добро и уважение между людьми.
